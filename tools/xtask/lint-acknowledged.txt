# Findings `cargo xtask lint` has seen and that belong to someone else to resolve.
#
# The lint reports the finding; whoever owns the code decides whether it is a bug, a deliberate
# choice, or a documented deviation. A row here prints as ACK and does not fail the build. Anything
# NOT on this list does fail, so the list is a ratchet, not an amnesty.
#
# Do NOT add a row for your own code. Annotate it instead:
#     // ORDER-OK: <why a randomised iteration order cannot leak here>
#     // LINT-OK:  <why this float-to-int cast is not a fidelity question>
# A row is for code that is not yours to touch.
#
# Format:  <path fragment>|<rule keyword>|<owner> -- <reason and what would clear it>
#
# Rule keywords: "as i32", "HashMap"
